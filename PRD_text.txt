Do not use future sensor values as input features.
Use chronological train/validation/test splits to avoid temporal leakage.
Because missed failures can be more costly than false alarms, report:
 Precision
 Recall
 F1

Component 2.1: Predictive Maintenance Model (Classification)
What to Build
A machine learning model that predicts the probability of machine failure within the next 48 hours.
Business Problem
Unplanned machine downtime costs manufacturing companies millions annually. Early detection of failure patterns allows
preventive maintenance scheduling, reducing downtime by 30-40%.
Data Requirements
 Features: temperature, vibration, pressure, current, energy_kwh, production_count, operating_hours
 Engineered Features: rolling means (6 readings), rate of change, temperature-vibration interaction
 Target: failure_risk (0 = safe, 1 = failure imminent)
 Data Size: ~50,000 rows
Technical Approach
Model Selection:
1. Random Forest Classifier (baseline, interpretable)
2. XGBoost Classifier (advanced, better performance)
3. Compare both, choose best
Feature Engineering:
 Create these features:
- temp_rolling_mean (last 6 readings)
- vib_rolling_mean (last 6 readings)
- temp_rate (rate of temperature change)
- vib_rate (rate of vibration change)
- temp_vib_interaction (temperature × vibration)
- energy_efficiency (production / energy)
- hour_of_day (categorical)
- is_weekend (boolean)
- days_since_maintenance (from maintenance history)
Handling Imbalance:

 // authMiddleware.js
const verifyToken = (req, res, next) => {
    const token = req.header('Authorization')?.replace('Bearer ', '');
    if (!token) return res.status(401).json({ error: 'Access denied' });
    try {
        const verified = jwt.verify(token, process.env.JWT_SECRET);
        req.user = verified;
        next();
    } catch (error) {
        res.status(401).json({ error: 'Invalid token' });
    }
};
const requireRole = (...roles) => {
    return (req, res, next) => {
        if (!roles.includes(req.user.role)) {
            return res.status(403).json({ error: 'Insufficient permissions' });
        }
        next();
    };
};

 // ChatInterface.jsx
const ChatInterface = () => {
    const [messages, setMessages] = useState([]);
    const [input, setInput] = useState('');
    const [isLoading, setIsLoading] = useState(false);
    const { sendMessage } = useAIAssistant();
    
    const handleSend = async () => {
        const userMessage = { role: 'user', content: input };
        setMessages([...messages, userMessage]);
        setInput('');
        setIsLoading(true);
        
        try {
            const response = await sendMessage(input);
            const assistantMessage = { 
                role: 'assistant', 
                content: response.answer,
                data: response.data 
            };
            setMessages(prev => [...prev, assistantMessage]);
        } catch (error) {
            // Handle error
        } finally {
            setIsLoading(false);
        }
    };
    
    return (
        <div className="h-full flex flex-col">
            <ChatHeader />
            <MessageList messages={messages} />
            {isLoading && <TypingIndicator />}
            <QuickQuestions onSelect={handleQuickQuestion} />
            <ChatInput value={input} onChange={setInput} onSend={handleSend} />
        </div>
    );
};
